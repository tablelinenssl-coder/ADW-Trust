## 🌿 About ADW Trust

ADW Trust is dedicated to providing direct, verified humanitarian relief across Sri Lanka. Operating with dual liaison bases in **Colombo, Sri Lanka** (hospital distribution hub) and **Hanover, Germany** (European coordination), the trust delivers critical medical supplies, school hydration facilities, educational resources, and ecological care with **100% direct allocation and zero intermediary overhead**.

---

## 🎯 Four Core Pillars of Relief

### 1. 👁️ Cataract Surgery Support
- **Direct Hospital Supply:** Procures and delivers high-grade foldable intraocular lenses (IOLs), viscoelastic ophthalmic consumables, and sterile surgical packs directly to public hospital surgical theaters.
- **Regular Surgeries:** On average, supports approximately **27 cataract surgeries every month** across island-wide government hospitals.
- **Vision Clarity Simulator:** Interactive before/after simulation slider demonstrating the life-changing impact of restored vision.

### 2. 💧 Drinking Water, Sanitation & Hygiene in Schools
- **Safe School Hydration:** Equipping rural schools with durable water dispensers, filtration systems, and clean drinking stations.
- **Child Health & Focus:** Providing healthy hydration alternatives to sugary drinks, improving memory and classroom concentration, and promoting oral hygiene with fluoridated water.

### 3. 🎓 Support for Rural Schools
- **Classroom Learning Dignity:** Supplying curriculum textbooks, stationery bundles, geometry sets, and durable study desks to rural school classrooms.
- **Sanitation Facilities:** Restoring student washrooms and hygiene points in direct partnership with village school teachers.

### 4. 🌱 Environment & Tree Planting
- **Community Reforestation:** Facilitating community-led tree planting events across rural villages.
- **School Nature Stewardship:** Conducting environmental workshops to teach students native sapling care (e.g., Kumbuk, Mee, and fruit trees).
- **Sustainability:** Prioritizing native flora and sustainable environmental practices.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/tablelinenssl-coder/ADW-Trust.git
   cd ADW-Trust
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
